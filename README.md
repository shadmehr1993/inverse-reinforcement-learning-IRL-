# inverse-reinforcement-learning-IRL-
This project applies inverse reinforcement learning (IRL) to optimize HVAC operations in district buildings. By learning reward functions from expert behavior, we aim to enhance energy efficiency while maintaining occupant comfort. Our approach provides actionable insights and tools for improving HVAC performance in real-world applications.
